# Pipe Flow & Pressure Drop Calculator — Test Report

This report documents tests performed on the Pipe Flow & Pressure Drop Calculator to verify that its calculations and input validation work as intended.

## 2. Test Environment

* Programming language: C++
* IDE: Code::Blocks
* Compiler: GNU GCC
* Interface: Console application

## 5. Conclusion

The program compiled and ran successfully in Code::Blocks. The normal test produced reasonable results, and the invalid-input tests confirmed that the program rejects the tested invalid values. The menu also allowed repeated calculations and normal program termination.

Additional boundary tests should be performed to verify behavior near flow-regime transition values and with extremely large or small inputs.
